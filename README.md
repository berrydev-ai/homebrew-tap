# BerryDev AI Homebrew Tap

Homebrew formulae for BerryDev AI command-line tools.

## Install

```bash
brew install berrydev-ai/tap/slack-post
```

Or tap the repository first:

```bash
brew tap berrydev-ai/tap
brew install slack-post
```

## Formulae

- `slack-post`: posts messages to Slack using `chat.postMessage`.
- `gojq-mcp`: MCP server that runs jq filters against JSON.
